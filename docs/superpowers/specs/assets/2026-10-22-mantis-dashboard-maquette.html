Ce qui se passe

Le paramètre q est concaténé directement dans la requête SQL. Un attaquant non authentifié peut lire toute la table users.

Code concerné

140  def search(q):
141      db = get_db()
142      rows = db.execute(f"SELECT * FROM items WHERE name LIKE '%{q}%'")
143      return jsonify(rows)

Correctif proposé

- rows = db.execute(f"SELECT * FROM items WHERE name LIKE '%{q}%'")
+ rows = db.execute("SELECT * FROM items WHERE name LIKE ?", (f"%{q}%",))
